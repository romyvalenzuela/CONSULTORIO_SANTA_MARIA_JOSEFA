# CONSULTORIO SANTA MARÍA JOSEFA

## 1. DESCRIPCIÓN DEL PROYECTO
El presente proyecto consiste en el desarrollo de una base de datos para el Consultorio Santa María Josefa. 
El objetivo es organizar la información del consultorio para ser publicada en la página web.
Se incluye información sobre horarios de atención, especialidades médicas, médicos y datos de contacto.

## 2. DESARROLLO DE LAS ACTIVIDADES

### Actividad 1: Identificación de la información
Se determinó que la información más solicitada por los pacientes es:
- Horarios de atención
- Días disponibles 
- Especialidades médicas

### Actividad 2: Recopilación de datos
Se recopiló la información en una tabla de Excel con las especialidades, médicos, días y horas de atención.

### Actividad 3: Revisión de datos
Se revisó la información para evitar datos duplicados o incorrectos.

### Actividad 4: Modelo de la base de datos
Se crearon 6 tablas para guardar la información del sitio web:
1. **CONTACTO**: Guardar teléfono, correo y dirección.
2. **NOSOTROS**: Guardar la información del consultorio.
3. **ESPECIALIDAD**: Guardar la especialidad médica.
4. **HORARIO**: Guardar los días y horas de atención.
5. **UBICACIÓN**: Guardar la dirección del consultorio.
6. **IMAGEN**: Guardar las imágenes de la página web

### Actividad 5: Implementación
Se creó la base de datos en PostgreSQL con el nombre 'consultorio_santa_maría_jósefa' usando pgAmin 4.

### Herramientas Utilizadas
- PostgreSQL 10
- pgAmin 4
- Github

Se logró crear una base de datos que organizar la información principal del Consultorio Santa María Jósefa.
